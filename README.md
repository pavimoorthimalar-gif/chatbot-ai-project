# 🤖 AI CLI Chatbot

A conversational AI chatbot built using Python and Google Gemini API.

## 📌 Project Description

This project is a Command Line Interface (CLI) based AI chatbot that allows users to interact with an AI assistant through the terminal.

The chatbot uses Google's Gemini AI model to generate intelligent responses and supports conversation history, user commands, and error handling.

## ✨ Features

- 💬 Chat with AI assistant
- 🧠 Gemini AI powered responses
- 📝 Conversation history tracking
- 🧹 Clear conversation history
- ❓ Help command support
- 🚪 Exit command
- ⚠️ API error handling

## 🛠️ Technologies Used

- Python
- Google Gemini API
- python-dotenv
